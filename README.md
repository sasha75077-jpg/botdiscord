# 🤖 Melancholia — Discord-бот + веб-панель

Мультисерверный Discord-бот (Python) + веб-панель: Cloudflare Pages (фронт) + Cloudflare Workers (API) + Cloudflare D1 (база панели). Локальная `bot.db` бота двусторонне синхронизируется с облаком.

## 🏗️ Архитектура

```
Discord ──▶ Бот (Python, локально, bot.db) ⇄ Workers API ⇄ D1
                                                        ↕
                                              Pages (React-панель)
```

* **Бот** работает локально (`python main.py`), пишет в `bot.db`, синкает изменения на сайт и забирает изменения с сайта (поллинг ~30–60 сек).
* **Одновременно — только один инстанс бота.** Два запущенных бота дадут дубли постов и синков.
* Старый FastAPI-бэкенд в `backend/` больше не используется.

## ✨ Возможности

### 🔐 Вход и роли
* Вход через Discord OAuth + вход овнера по email/паролю. Гость без общих серверов видит только витрину.
* Роли: owner / admin / recruiter / user (+ stranger-гость). Выдача: овнер — любые, админ — только recruiter/user своего сервера.
* Привязка Discord-ролей к панельным (несколько на роль) — сверка каждые 10 минут и при смене ролей; снятие Discord-роли снимает автоназначенную. Команда `/sync_roles` — сверка вручную.
* Переключатель серверов в шапке, сессия тихо обновляет роль при загрузке.
* Тёмная тема: как в системе + ручной переключатель в шапке.

### 📝 Контракты (9 типов + курьер еды)
* Подача с сайта (скрины грузятся в Discord-канал, в базе только CDN-ссылки; товары — 2 окна: погрузка/доставка) и командой `/контракт` в Discord. Вставка картинок по Ctrl+V.
* Очереди разделены по серверам. Сначала «Взять» (можно перехватить), потом Принять/Отклонить — и на сайте, и в Discord. После решения карточка показывает статус + кто решил, кнопки снимаются.
* Напоминалка: взял и молчишь 10+ минут — тегнут со ссылкой.
* Удаление контрактов — кнопка у админа в карточке.
* Выплаты по типам видны в форме; прайс правится на сайте и в боте, синхрится в обе стороны.

### 📨 Заявки в семью
* Подача с сайта (вопросы настраиваются) и командой `/заявка` (модалка из тех же вопросов). Член семьи / принятый повторно подать не может.
* Очередь, взять/перехватить/принять/отклонить — и там, и там. Чат кандидата: пишет только взявший (+админ), мост Discord-тред ⇄ сайт. Незнакомцы видят только витрину серверов.

### 💰 Премии (недельные)
* Подача за текущую неделю с сайта и из Discord. После понедельника 00:00 МСК неделя закрыта везде.
* Принятие на сайте (сумма = сумма прайсов) и в Discord (точный расчет с рангами). Кнопки в Discord вечные.
* TXT-выгрузка принятых (static, сумма, коммент) + static правится в профиле.

### 📈 Ранги и повышения
* Лестница рангов на сайте: привязка к Discord-ролям, требования (семейные/личные), добавление рангов. Бот подтягивает за ~10 минут.
* В повышение идут дары/товары/ателье/сдача (семейные) и тюнинг/курьер (личные); активация и добыча не засчитываются.
* Заявки на повышение (main/alt) — подача в Discord, рассмотрение там же и частично на сайте. Лестница постится в Discord-канаaleleй и обновляется сама.
* Таблица семьи: контракты и прогресс каждого. Свой ранг виден в дешборде и профиле.

### 📢 Панели и уведомления (настройки на сайте, раздел «Уведомления»/«Панели»)
* Каналы: контрактов, заявок, премий, повышений (заявки и лестница — разные), прайса, логов; теги ролей на новые контракты/заявки повышений.
* Админ-хаб и панель игрока постятся из сайта, закрепляются, обновляются сами.
* Прайс-эмбед с категориями обновляется сам, при смене канала переезжает.
* Журнал ошибок бота виден овнеру на странице ролей.

### 👥 Пользователи
* Страница «Семья» (только holders FAMQ-роли): авы, панельные роли, счетчики контрактов, переход к контрактам человека.
* Дешборд: онлайн/состав Discord живьем, админы/рекруты, свои контракты.

## 🚀 Запуск бота

```bash
pip install -r requirements.txt
# .env: DISCORD_TOKEN, GUILD_IDS="id1,id2", PANEL_API_URL, PANEL_SYNC_SECRET
python main.py
```

`.env`, `credentials.json`, `bot.db` — локально, в git не лежат. Для переезда на другой ПК скопируй эти три файла (бот там подхватит миграции сам).

## ☁️ Деплой

```bash
# API
cd workers/api && npx wrangler deploy
# Секреты воркера: DISCORD_CLIENT_ID, DISCORD_CLIENT_SECRET, DISCORD_BOT_TOKEN, SECRET_KEY, OWNER_EMAIL, OWNER_PASSWORD, SYNC_SECRET
# Фронт: git push (Pages собирает сам) или
cd frontend && npm run build && npx wrangler pages deploy dist --project-name=botdiscord
```

Переменная Pages: `VITE_API_URL=https://<api>.workers.dev` (без `/api` на конце).

## 🐛 Troubleshooting

* **403 от API бота** — проверь `PANEL_SYNC_SECRET` в `.env` и секреты воркера; Python-запросы идут с браузерным UA (Cloudflare режет дефолтный).
* **Пустые списки/403 на сайте** — выйди и войди заново (роль в сессии обновляется при входе + тихо при загрузке).
* **Кнопки в Discord мертвы** — рестартни бота (вьюхи регистрируются при старте).
* **Панель не постится с сайта** — смотри статус задачи на странице + `bot_logs` + консоль бота.
* **Дубли постов** — убедись что запущен один инстанс бота.
