# 🌐 Веб-панель управления - Архитектура

## 📋 Общая концепция

### Три уровня доступа:

1. **Owner (Владелец бота)** - Вы
   - Видит ВСЕ серверы
   - Глобальные настройки бота
   - Управление любым сервером
   - Аудит логи всех действий
   - Статистика по всем серверам

2. **Admin (Администратор сервера)**
   - Видит только СВОЙ сервер
   - Настройки своего сервера
   - Управление контрактами
   - Управление заявками
   - Настройка Google Sheets

3. **User (Пользователь)**
   - Отправка контрактов
   - Подача заявки в семью
   - Просмотр своей статистики

---

│                    / (Главная страница)                      │

## 🔐 Авторизация Discord OAuth2

### Процесс авторизации:

```
1. User нажимает "Войти через Discord"
   ↓
2. Редирект на Discord OAuth2
   https://discord.com/api/oauth2/authorize
   ↓
3. User разрешает доступ
   ↓
4. Discord редиректит обратно с кодом
   https://yoursite.pages.dev/auth/callback?code=...
   ↓
5. Backend обменивает код на токен
   ↓
6. Backend получает данные пользователя из Discord
   ↓
7. Backend проверяет роль (Owner/Admin/User)
   ↓
8. Backend создает JWT токен
   ↓
9. Frontend сохраняет JWT и показывает соответствующую панель
```

## 📦 Технологический стек

### Frontend (Cloudflare Pages):
- **React** (уже есть в `frontend/`)
- **TailwindCSS** для стилизации
- **React Router** для навигации
- **Axios** для API запросов
- **React Hook Form** для форм

### Backend (Railway/VPS):
- **FastAPI** (уже есть в `backend/`)
- **SQLite/PostgreSQL**
- **Discord OAuth2**
- **JWT для сессий**
- **Google Sheets API**

### Деплой:
- **Frontend:** Cloudflare Pages (автодеплой из GitHub)
- **Backend:** Railway или VPS
- **База данных:** SQLite (для начала) или PostgreSQL
