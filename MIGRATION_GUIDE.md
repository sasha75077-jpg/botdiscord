## Как работает multi-guild

### 1. Автоматическая регистрация серверов

При запуске бота все серверы автоматически регистрируются в БД:

```python
# При старте бота
for guild in bot.guilds:
    await register_guild(str(guild.id), guild.name, icon_url)
```

При добавлении на новый сервер:
```python
# Событие on_guild_join
async def on_guild_join(self, guild):
    await register_guild(str(guild.id), guild.name, icon_url)
```

### 2. Модульная система

Каждый сервер имеет свои включенные/выключенные модули:

```python
# Проверка перед выполнением
if await is_module_enabled(guild_id, "contracts"):
    # Выполнить логику модуля
```

Модули хранятся в таблице `guild_modules`:
- `contracts` - импорт из Google Sheets
- `bonus_reports` - система бонусов
- `promotion_reports` - система повышений
- `ranks` - система рангов
- `cooldowns` - кулдауны
- `admin_panel` - админ панель
- `user_panel` - пользовательская панель

### 3. Настройки по серверам

Каждый сервер имеет свои настройки в `guild_settings`:

```python
# Получить настройку для конкретного сервера
value = await get_setting("setting_key", guild_id)

# Установить настройку
await set_setting("setting_key", "value", guild_id)
```
