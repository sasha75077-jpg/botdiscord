# ❓ FAQ - Часто задаваемые вопросы

## Общие вопросы

### Что такое мультисерверный режим?

Мультисерверный режим позволяет одному боту работать на нескольких Discord серверах одновременно. Каждый сервер имеет:
- Свои контракты и пользователей
- Свои настройки и модули
- Свою Google Sheets таблицу
- Свои каналы и роли

### Могу ли я использовать бота только на одном сервере?

Да! Бот автоматически поддерживает как один, так и множество серверов. Просто добавьте его на свой сервер и настройте.

### Нужно ли мне мигрировать со старой версии?

Да, если у вас уже был запущен бот версии 1.0. Запустите миграции по порядку:
```bash
python migrate_to_v2.py
python migrate_add_sheets_settings.py
python migrate_add_channel_settings.py
```

## Настройка

### Как добавить бота на новый сервер?

1. Создайте invite ссылку в Discord Developer Portal
2. Добавьте бота на сервер
3. Бот автоматически зарегистрирует сервер в БД
4. Настройте каналы: `/setup_channels`
5. (Опционально) Настройте Google Sheets: `/setup_sheets`

### Какие права нужны боту?

Минимальные права:
- Read Messages/View Channels
- Send Messages
- Embed Links
- Attach Files
- Read Message History
- Manage Messages (для удаления сообщений)
- Manage Roles (если бот выдает роли)

### Где хранятся настройки?

Все настройки хранятся в SQLite базе данных `bot.db` в таблице `guild_settings`. Каждый сервер имеет свои настройки.

## Google Sheets

### Обязательно ли настраивать Google Sheets?

Нет. Google Sheets интеграция опциональна. Бот работает без неё, но не будет импортировать контракты из таблиц.

### Можно ли использовать одну таблицу на все серверы?

Технически да, но **не рекомендуется**. Каждый сервер должен иметь свою таблицу для изоляции данных.

### Как часто импортируются контракты?

По умолчанию каждые 60 секунд (`POLLING_INTERVAL=60` в `.env`). Можно изменить интервал.

### Почему контракты не импортируются?

Проверьте:
1. Включен ли импорт: `/setup_sheets` → должно быть "✅ Включено"
2. Настроен ли `sheet_id`: `/setup_sheets`
3. Есть ли доступ у Service Account к таблице
4. Включен ли модуль `contracts` для сервера
5. Логи бота на наличие ошибок

### Что делать если Service Account не имеет доступа?

1. Откройте файл credentials.json
2. Найдите поле `client_email` (например: `bot@project.iam.gserviceaccount.com`)
3. Откройте Google Sheets таблицу
4. Нажмите "Поделиться" (Share)
5. Вставьте `client_email` и дайте права "Редактор" (Editor)

## Credentials

### Что такое credentials файл?

Это JSON файл с ключами доступа Google Service Account. Он нужен для подключения к Google Sheets API.

### Где взять credentials?

1. Google Cloud Console: https://console.cloud.google.com/
2. APIs & Services → Credentials
3. Create Service Account
4. Create Key → выбрать JSON
5. Скачать файл

### Нужен ли отдельный credentials для каждого сервера?

**Рекомендуется, но не обязательно**. Можно использовать один credentials для всех серверов, но лучше разделить для безопасности.

### Как добавить credentials для нового сервера?

```bash
# Скопировать в папку credentials
cp your-credentials.json credentials/YOUR_GUILD_ID.json

# Настроить путь через команду
/setup_sheets credentials_path:credentials/YOUR_GUILD_ID.json
```

### Безопасно ли хранить credentials на сервере?

Credentials должен быть защищён:
- ❌ Не добавляйте в git (проверьте `.gitignore`)
- ❌ Не публикуйте публично
- ✅ Храните на защищённом сервере
- ✅ Используйте права доступа к файлу (chmod 600)

## Каналы и роли

### Как настроить каналы для бота?

```
/setup_channels 
  admin_contracts_channel: #ваш-канал
  pending_counter_channel: #другой-канал
  pending_ping_role: @роль
```

### Можно ли использовать один канал для всего?

Да, можно указать один и тот же канал для всех настроек.

### Что делать если бот не пингует роль?

Проверьте:
1. Роль настроена: `/setup_channels`
2. Роль не равна `0` или пустой строке
3. У бота есть право "Mention Everyone" или роль mentionable

### Счетчик контрактов не появляется

Проверьте:
1. Канал настроен: `/setup_channels pending_counter_channel:#канал`
2. У бота есть права отправки сообщений в канал
3. Модуль `contracts` включен

## Модули

### Что такое модули?

Модули — это функции бота, которые можно включать/выключать для каждого сервера отдельно:
- `contracts` - импорт и управление контрактами
- `user_panel` - панель профиля пользователя
- `admin_panel` - панель администратора
- `bonus_reports` - отчеты на бонусы
- `promotion_reports` - отчеты на повышение

### Как включить/выключить модуль?

Через SQL (пока нет команды):
```sql
-- Выключить модуль
UPDATE guild_modules 
SET is_enabled = 0 
WHERE guild_id = 'YOUR_GUILD_ID' AND module_name = 'contracts';

-- Включить модуль
UPDATE guild_modules 
SET is_enabled = 1 
WHERE guild_id = 'YOUR_GUILD_ID' AND module_name = 'contracts';
```

### Модули включены по умолчанию?

Да. Если модуль не настроен в `guild_modules`, он считается включенным.

## База данных

### Какая база данных используется?

SQLite - лёгкая встраиваемая БД. Файл `bot.db` в корне проекта.

### Можно ли использовать PostgreSQL?

Код написан для SQLite, но при необходимости можно портировать на PostgreSQL. Потребуется изменить `database.py` и схемы.

### Как сделать бэкап БД?

```bash
# Простое копирование файла
cp bot.db bot_backup_$(date +%Y%m%d_%H%M%S).db

# Или через sqlite3
sqlite3 bot.db ".backup bot_backup.db"
```

### Как просмотреть данные в БД?

```bash
# Открыть в sqlite3
sqlite3 bot.db

# Просмотреть серверы
SELECT * FROM guilds;

# Просмотреть настройки сервера
SELECT * FROM guild_settings WHERE guild_id = 'YOUR_GUILD_ID';
```

## Web-панель

### Есть ли веб-интерфейс?

Да! Backend на FastAPI в папке `backend/`, Frontend на React в `frontend/`.

### Как запустить веб-панель?

```bash
# Backend
cd backend
pip install -r requirements.txt
python run.py

# Frontend (в другом терминале)
cd frontend
npm install
npm run dev
```

### Кто может заходить в веб-панель?

- **Owner** - полный доступ ко всем серверам
- **Admin** - доступ к своему серверу
- Авторизация через Discord OAuth2

## Производительность

### Сколько серверов может обслуживать бот?

Теоретически неограниченно. Практически зависит от:
- Количества контрактов на импорт
- Частоты опроса Google Sheets
- Ресурсов сервера

Рекомендуется до 50-100 активных серверов на одном инстансе.

### Как оптимизировать производительность?

1. Увеличить `POLLING_INTERVAL` (реже опрашивать Sheets)
2. Выключить неиспользуемые модули
3. Использовать PostgreSQL вместо SQLite (для >20 серверов)
4. Включить кэширование в `database.py`

### Бот лагает при большом количестве серверов

Проверьте:
1. Логи на ошибки Google Sheets API (rate limits)
2. Размер `bot.db` (SQLite медленнее на больших БД)
3. Количество одновременных запросов к БД
4. Использование памяти и CPU

## Ошибки

### "guild_id не указан в контракте"

Эта ошибка была в старой версии. Обновите код до последней версии (задача #1 выполнена).

### "SHEET_ID не настроен"

Настройте Sheet ID для сервера:
```
/setup_sheets sheet_id:YOUR_SHEET_ID
```

### "credentials файл не найден"

Поместите credentials.json в папку `credentials/`:
```bash
cp your-credentials.json credentials/YOUR_GUILD_ID.json
/setup_sheets credentials_path:credentials/YOUR_GUILD_ID.json
```

### "Таблица не найдена"

1. Проверьте правильность Sheet ID
2. Убедитесь что Service Account имеет доступ к таблице
3. Проверьте что таблица существует и не удалена

### Бот не отвечает на команды

1. Проверьте что бот онлайн
2. Проверьте права бота на сервере
3. Проверьте что команды синхронизированы (перезапустить бота)
4. Посмотрите логи на ошибки

## Разработка

### Как добавить новую команду?

1. Создать функцию в соответствующем cog (`cogs/*.py`)
2. Добавить декоратор `@app_commands.command()`
3. Перезапустить бота для синхронизации команд

### Как добавить новую настройку?

1. Добавить ключ в `guild_settings` через миграцию
2. Обновить команду `/setup_channels` или `/setup_sheets`
3. Использовать `get_setting(key, guild_id)` в коде

### Как добавить новый модуль?

1. Добавить запись в `guild_modules`
2. Проверять `is_module_enabled(guild_id, module_name)` перед выполнением
3. Документировать модуль в README
